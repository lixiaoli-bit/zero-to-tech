动手换芯 · /api/analyze

1 导入库 打开backend/main.py

from pypinyin import lazy_pinyin, Style from snownlp import SnowNLP

2 定义分数 → 标签翻译

def score_label(score): if score >= 0.6: return "偏积极" elif score <= 0.4: return "偏消极" else: return "中性"

3 新 analyze 核心

@app.post("/api/analyze") def analyze(req: AnalyzeRequest): text = req.text score = round(SnowNLP(text).sentiments, 2) return { "text": text, "score": score, "label": score_label(score), "pinyin": " ".join(lazy_pinyin(text, style=Style.TONE)) }
接口约定不变 —— 路径、方法、请求体、返回字段完全一致，前端一行不改。

见证效果 · 模型边界

启动前端npm run dev 启动后端 一定是到main文件夹下：fastapi dev
http://localhost:8000/docs 找到 /api/analyze 端点，点击 "Try it out"，输入： {"text": "今天的风很轻"} 然后点击 "Execute"。
“我特别喜欢这部电影” → 0.95 偏积极
“太失望了，再也不来了” → 0.00 偏消极
“今天下午三点开会” → 0.26 偏消极 (中性陈述翻车)
“呵呵，真是太棒了呢” → 0.94 偏积极 (反讽识别失败)
模型没有常识，只有训练时见过的世界。snownlp 擅长商品评论，对中性陈述和反讽力有不逮。用任何模型前，先弄清它的边界。
