Certbot 一键搞定 HTTPS

推荐方案

最推荐 你用 certbot 这个免费工具，它会自动帮你申请证书并修改 Nginx 配置，全程就几分钟。 快速 · 自动化

安装 Certbot

按你的系统选一条执行：

# Ubuntu / Debian sudo apt update && sudo apt install certbot python3-certbot-nginx -y # CentOS / RHEL sudo yum install certbot python3-certbot-nginx -y
一键配置证书

把域名换成你自己的，命令会自动修改 Nginx 配置：

sudo certbot --nginx -d www.ashao.dpdns.org
执行后，按提示输入邮箱，同意条款。Certbot 会自动搞定证书申请，并把 Nginx 配置改成支持 HTTPS。
测试并重载
sudo nginx -t && sudo systemctl reload nginx
证书生效后，访问 https://www.a.com 小锁头图标，不安全提示消失
后续建议 & 维护
证书自动续期
Certbot 已设置定时任务，证书到期前自动续期，无需手动操作。
重启服务器注意
Nginx 已设置开机自启（enabled），但请确认 Docker 里的 OpenResty 容器不会再次自动启动占用 443 端口。
如果 OpenResty 容器又跑起来，执行： sudo docker rm -f 04eb912e041f
定期检查： curl -I https://www.ashao.dpdns.org 确认网站状态
最终能成功访问 https://www.ashao.dpdns.org 并看到 200 OK 说明你的 Nginx、SSL 证书和域名解析都已完美工作。 安全就绪
