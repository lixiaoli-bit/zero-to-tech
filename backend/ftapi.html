FastAPI · 后端框架 从手搓到自动化

框架 · 把杂活打包复用

后端框架管的是：接住请求、解析内容、把响应发回去。我们只需要关心 “这个路径，该返回什么数据”。

手搓版 vs FastAPI 版 —— 上一节我们手写了路由、状态码、响应头、dumps、encode、404…… 而 FastAPI 一行装饰器全包了。

主流框架认脸

  • Flask — 老牌轻量，入门经典
  • Django — 大而全，自带ORM和管理后台
  • FastAPI — 专为API而生，代码少、自动校验、自动文档

概念相通，把 FastAPI 用明白，Flask/Django 都是熟面孔。

两个角色：FastAPI 与 uvicorn

FastAPI — 定义接口，组织响应
uvicorn — 运行服务器，监听端口

进后端项目---激活虚拟环境 source .venv/bin/activate # 若提示符没带括号

安装：pip install "fastapi[standard]" （套餐包含 uvicorn、starlette、pydantic 等）

铺垫结束，正主登场。先把手搓版留作纪念mv main.py handmade.py

新建 main.py，写 FastAPI 版 重写 /api/profile · 感受减法

main.py from fastapi import FastAPI app = FastAPI() profile = { "heroTitle": "关于我", "heroSubtitle": "项目，创意，灵感，心得，我的作品", } @app.get("/api/profile") def get_profile(): return profile
手搓版if self.path 路由判断、send_response(200)、json.dumps、404兜底...
FastAPI 版@app.get(...) 装饰器，自动 JSON，自动 404
自动文档/docs 自动生成，可交互调试

启动命令

uvicorn main:app --reload # 手动挡uvicorn 去找 main.py 文件里的 app（这里不写 .py） fastapi dev # 快捷命令，默认 main.py，带 --reload

以后统一用 fastapi dev，简洁且和官网一致。

访问： http://127.0.0.1:8000/api/profile

访问不存在目录，他还404，比我们手戳的都周到

惊喜的是我们的api长出自己的文档http://127.0.0.1:8000/docs

加一个 POST 接口：/api/analyze

先定约定：请求体 { "text": "..." } ，响应形状含 text / score / label / pinyin（后三个占位）。

main.py (增量) 顶部加 from pydantic import BaseModel profile后面加 class AnalyzeRequest(BaseModel): text: str 末尾加 @app.post("/api/analyze") def analyze(req: AnalyzeRequest): return { "text": req.text, "score": 0.5, "label": "偏平静", "pinyin": "（模块 6 再说）", }
BaseModel 的威力：自动收字节、解析 JSON、校验字段类型，缺字段或类型错自动返回 422 错误，文档同步更新。

测试与报错

curl http://localhost:8000/api/analyze \ -H "Content-Type: application/json" \ -d '{"text": "今天的风很轻"}' 上面代码加-i 为的是看清
上面代码显示错误的话，按照这个步骤测试 http://localhost:8000/docs 找到 /api/analyze 端点，点击 "Try it out"，输入： {"text": "今天的风很轻"} 然后点击 "Execute"。如果 Swagger UI 能成功，说明服务器端没问题，是 curl 命令的问题。
# 方式 C：从文件读取 echo '{"text": "今天的风很轻"}' > data.json curl -X POST http://localhost:8000/api/analyze \ -H "Content-Type: application/json" \ -d @data.json

故意写错字段名 {"txt": "..."} 会得到 422 Unprocessable Entity；代码内 req.txt 笔误则返回 500，终端红字 traceback 明确提示 AttributeError。

惊喜：自动文档 + __pycache__

  • 浏览器打开 http://localhost:8000/docs，接口说明书自动生成，支持 Try it out。
  • __pycache__/ 是 Python 自动生成的缓存目录，应加入 .gitignore。
  • 依赖清单：pip freeze > requirements.txt，把 fastapi、uvicorn 等整套记下来。

这一节带走什么

  • 框架 = 把后端杂活打包复用，我们手搓过，所以确切知道 FastAPI 替我们干了什么。
  • FastAPI 管定义接口，uvicorn 管运行；fastapi dev 统一启动。
  • 先定约定（请求/响应形状），再用 BaseModel 声明，自动校验+文档。
  • 目前 score/label/pinyin 是占位，模块 6 换真的，调用方毫无感知。
  • 更新 .gitignore（忽略 __pycache__）和 requirements.txt。
