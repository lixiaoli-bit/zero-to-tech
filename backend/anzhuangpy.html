Python · 后端环境 · 虚拟环境 venv + pip + requirements

安装 Python

先确认版本：

python3 --version # 或 python --version

建议直接官网下载最新稳定版： python.org/downloads

python 与 python3：macOS/Linux 通常 python3 指向 Python 3，python 可能指向 2.x 或为空；Windows 安装器通常直接 python 就是 3.x。哪个能用用哪个。

查看当前 Python 路径

which python3 # macOS/Linux
where python # Windows CMD

想列出所有候选：

which -a python3 # macOS/Linux

生存技能：环境问题先 which python3 或 where python，一眼看穿真相。

venv 与环境隔离

一台电脑可住多个 Python，每个项目用 venv 绑定专属版本和依赖，互不影响。

创建虚拟环境（示例）

cd ~/project_A
python3.12 -m venv .venv

激活：

source .venv/bin/activate # macOS/Linux
.venv\Scripts\activate # Windows 并且是cmd运行

提示符变为 (.venv)，此时 python 和 python3 都指向项目专属 Python。

退出：

deactivate
常见疑问
• 两个项目 .venv 都叫 .venv，可用 --prompt 自定义提示符：
python3 -m venv --prompt=project_A .venv → 显示 (project_A)
• 如果已经在用 conda，建议退出改用 venv（课程采用 venv）：
conda config --set auto_activate_base false 然后重启终端。

在项目中创建 backend 与 .venv

cd ~/zero-to-tech
mkdir backend
cd backend
python3 -m venv --prompt=zero-to-tech .venv
source .venv/bin/activate # Windows 并且cmd运行，gitpush 还有点问题 .venv\Scripts\activate

验证：

which python # → /Users/.../backend/.venv/bin/python
which python3 # → 同样指向 .venv

.venv 不进 Git，在 .gitignore 中加入 backend/.venv/。

vscode 装插件 Python Environments，总端（顶部有terminal）自动识别虚拟环境

第一个 Python 程序

新建 first_json.py，生成 JSON：

import json

site_name = "zero-to-tech"

def make_data():
data = {"message": "hello, world", "from": site_name}
return json.dumps(data)

print(make_data())

运行：

python3 first_json.py
# 输出: {"message": "hello, world", "from": "zero-to-tech"}

认一认 Python 结构

  • import：引入库（标准库如 json, datetime, random, os, http.server）
  • 变量：site_name = "zero-to-tech"
  • 函数 + 缩进：def make_data(): 缩进表示代码块
  • print()：打印到终端

装第一个第三方库：requests

新建 api_demo.py：

import requests

resp = requests.get("https://api.ipify.org?format=json")
print(resp.json())

直接运行报错 ModuleNotFoundError，因为 requests 不是标准库，需安装：

pip install requests

装完查看落点：

pip show requests
# Location: /.../backend/.venv/lib/python3.x/site-packages

再运行：

python3 api_demo.py
# {'ip': '114.86.123.45'}

resp.json() 返回 Python 字典（单引号），与 json.dumps() 的 JSON 文本（双引号）不同。

requirements.txt · 依赖清单

生成依赖清单：前端靠 package.json 记依赖，Python 靠 requirements.txt。生成它

pip freeze > requirements.txt

查看内容：

cat requirements.txt
# certifi==2026.6.17
# charset-normalizer==3.4.8
# requests==2.34.2
# ...

别人拿到项目，一键安装：

pip install -r requirements.txt

这一节你应该带走什么

  • 后端先有运行环境：Python 从官网装，python3 --version 验证。
  • 多个 Python 共存，用 which python3 排查；想用特定版本直接敲 python3.12。
  • venv 给每个项目专属 Python：python3 -m venv .venv + source .venv/bin/activate，deactivate 退出。
  • .venv 不进 Git；conda 用户可退出改用 venv。
  • 运行 Python 程序：python3 文件名.py。
  • 认得四个结构：import、变量、def + 缩进、字典≈JSON。
  • 标准库 import 即用；第三方库需 pip install，装进当前激活的 .venv。
  • pip freeze > requirements.txt 生成依赖清单，pip install -r 复现环境。
  • 已经能用 Python 生成 JSON 并调 API（requests 版 curl）。
