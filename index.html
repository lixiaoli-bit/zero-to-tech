目录与路径符号

~ 家目录
/ 根目录

Vim 基本操作（写文件）

用 Vim 创建并写入文件：

vim hello.txt
进入 Vim 后的操作步骤：
  1. 按 i 进入编辑模式（插入模式）
  2. 输入内容，例如 hello terminal
  3. 按 Esc 退出编辑模式
  4. 输入 :wq（保存并退出）如果报错，:q!不保存退出，sudo vim 进入
  5. 按回车

Mac 快速打开文件夹

在终端中执行：

open ~/zero-to-tech

该命令会通过访达（Finder）打开指定目录。

DNS 与端口基础概念

  • DNS：将域名翻译为 IP 地址。
  • 端口：同一台电脑上不同网络服务的入口标识。

浏览器访问网页流程

  1. 输入域名
  2. 浏览器向 DNS 查询对应的 IP 地址
  3. DNS 返回 IP
  4. 浏览器通过 IP 找到目标服务器
  5. 浏览器通过特定端口（如 80）访问服务
  6. 服务器返回网页内容
  7. 浏览器渲染显示

云服务器与 SSH 登录

购买云服务器后，通常获得：

  • 公网 IP 地址
  • 用户名（如 ubuntu 或 root）
  • 登录密码

SSH 远程登录命令

ssh 用户名@服务器公网IP

示例：

ssh ubuntu@123.45.67.89

登录成功后，终端提示符会变为类似：

ubuntu@your-server:~$

安装 Nginx（Web 服务器）

Nginx 职责：

  • 持续监听 80 端口
  • 响应 HTTP 请求，返回网页内容

安装步骤（Ubuntu 环境）

sudo apt update
sudo apt install nginx -y

sudo 执行时需要输入当前用户的密码。

检查 Nginx 运行状态

systemctl status nginx

看到 Active: active (running) 表示运行正常。这里输入ip地址就可以看到nginx的默认界面，至于ssh直接回车就可以

验证 Nginx 默认页面

Nginx 默认配置文件位置：

cat /etc/nginx/sites-available/default

找到关键配置行：

root /var/www/html;

表示网页文件存放在 /var/www/html 目录。

进入该目录查看：

cd /var/www/html
ls

默认页面文件通常为 index.nginx-debian.html。

查看其内容：

cat index.nginx-debian.html

该文件就是浏览器中默认页面对应的 HTML 源文件。
