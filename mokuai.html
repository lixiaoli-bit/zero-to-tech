项目结构 · 模块化改造

从单文件到多文件，模块化让代码更清晰：这是最原始的代码，我们要改造

zero-to-tech-4-1/
   index.html
   text-lab.html
   css/    (8 个样式文件)
   js/
     cards.js    ← 卡片飞入动画
     score.js    ← 分数动画
     nav.js     ← 导航高亮
     main.js    ← 入口文件
最后的核心变化： 每个 JS 文件通过 import / export 声明依赖，不再依赖全局变量和手动排序。

第三方库 · CDN 与模块引入-----------改

使用 anime.js 动画库，从 CDN 引入：

你完全可以把那个网址里的内容下载到本地、存成 anime.iife.min.js，再写 src="anime.iife.min.js">，效果一模一样。 之所以走 CDN，只是省得自己存一份——别人的服务器替我们存了。

<script src="https://cdn.jsdelivr.net/npm/animejs@4/lib/anime.iife.min.js"></script>

模块化改造后，改为按需导入：

import { animate, stagger } from "https://cdn.jsdelivr.net/npm/animejs@4/+esm";

每个模块只引入自己需要的功能，依赖关系清晰可见。

改造前 vs 改造后

传统 <script>

  • anime.js 挂在 window 全局
  • 四个 script，顺序不能乱，形成了暗依赖
  • 函数靠 window 全局共享
  • 找 CDN、塞 script、防撞名
  • 双击 HTML 即可运行

模块化 import

  • 每个文件 import 自己要的部分
  • 一个入口 main.js，依赖写在代码里
  • 显式 import / export，模块作用域
  • 一行 import，按需挑选
  • 必须通过服务器访问 (CORS 限制)

模块化代码示例

cards.js score.js nav.js 全部按照笔记修改

import { animate, stagger } from "https://cdn.jsdelivr.net/npm/animejs@4/+esm";

export function initCardsAnim() {
   animate(".card", {
     opacity: [0, 1],
     translateY: [24, 0],
     delay: stagger(120),
     duration: 700,
     ease: "outBack"
   });
}

我们再在 js 目录下，新建一个 main.js 文件

import { initNav } from "./nav.js";
import { initCardsAnim } from "./cards.js";
import { initScoreAnim } from "./score.js";

initNav();
initCardsAnim();
initScoreAnim();

改造后，HTML 中只需一行：

<script type="module" src="js/main.js"></script>

工程化 · 生态的力量

  • 模块化：每个文件独立作用域，依赖通过 import/export 声明
  • CDN 生态：一行 import 即可使用 anime.js 的 stagger、scrambleText 等功能
  • 开发服务器：模块化要求通过 HTTP 服务访问，可使用 Nginx 或本地 serve
  • 工程化第一招：模块化解决了全局污染和脚本顺序问题，为大型项目奠基
核心思想： “你写的东西默认只有自己看得见；想给别人用，得明文标 export；想用别人的，得明文写 import。”

部署与访问方式

模块化改造后，不能再双击 HTML 运行，必须通过服务器提供--这是遗留问题

  • 使用 Nginx 部署到服务器（如 3.5 节中的云主机）
  • 本地开发可用 npx serve 或 VS Code Live Server
  • 浏览器通过 http:// 访问，模块加载正常
# 使用 Nginx 部署
sudo cp -r zero-to-tech-4-1/* /var/www/html/
# 然后访问 http://你的服务器IP

本节课核心收获

  • 传统 <script> 组织方式存在 全局污染 和 顺序依赖 问题
  • 模块化 通过 import/export 解决上述问题，是工程化的第一步
  • 模块化代码需要 HTTP 服务器 环境运行，无法直接双击打开
  • 第三方库（如 anime.js）可通过 CDN + ESM 方式按需引入
  • 理解了 “工程化” 的基本含义：用工具和规范管理代码复杂度
